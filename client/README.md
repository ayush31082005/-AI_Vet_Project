# VioletVet frontend
Run `npm install` then `npm run dev` from client. Set VITE_API_URL and optional VITE_GOOGLE_CLIENT_ID in .env. Tailwind v4 and GSAP are configured. Online photos require internet. Public and authentication routes share Header/Footer; dashboards retain their own sidebar. Backend source was not supplied; API contracts remain assumptions from the previous client. Calendar preference is not sent to booking. Contact is a support page, not a submission form. Appointment rescheduling/cancellation, persistent AI history and advanced admin management remain incomplete.
